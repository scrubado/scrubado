# Scrubado

Scrubado is a two-sided marketplace connecting customers with independent residential cleaning professionals.

> Scrubado is currently the development codename for the project.

## Project Status

Early development / MVP planning.

## User Types

### Customers
Customers can:
- Create an account
- Manage their profile and addresses
- Request residential cleaning services
- Select available dates and times
- View booking status
- Communicate with their cleaner
- Review completed services

### Cleaners
Cleaning professionals can:
- Create an account
- Build a cleaner profile
- Define service areas
- Set availability
- View available jobs
- Accept bookings
- Manage scheduled jobs
- Mark jobs complete

### Administrators
Administrators can:
- Manage customers and cleaners
- Manage bookings
- Review platform activity
- Handle disputes and account issues
- Manage services and platform settings

## MVP

The first version will focus on:

1. Authentication
2. Customer profiles
3. Cleaner profiles
4. Services
5. Cleaner availability
6. Booking requests
7. Booking acceptance
8. Booking status
9. Basic administration

Payments, advanced matching, mobile applications, ratings, messaging, and other advanced features will be introduced after the core booking workflow is operational.

## Development Workflow

`main` — stable code

`develop` — integration and active development

`feature/*` — individual features and development work

Feature branches merge into `develop`.

Tested releases merge from `develop` into `main`.
